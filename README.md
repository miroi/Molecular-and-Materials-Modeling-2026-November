
# A One-Day Hybrid School on Molecular and Materials Modeling

## Event Details
* **Date:** 20 November 2026
* **Format:** Flexible Hybrid Format (Join us via Zoom or in-person)
* **Language:** English (Sessions are recorded for later viewing)

---

## Key Features

* **Hands-on Learning**  
  Participants use their own laptops to install and run the selected free software.

* **Practical Curriculum**  
  The school focuses on "learning by doing" through guided hands-on computer exercises.

* **Skill-Based Tasks**  
  Challenges are built directly on the techniques covered in the exercises.

* **Access Anywhere**  
  Sessions are conducted in English and are recorded for later viewing.

* **Shared Resources**  
  All working files and course materials will be shared with attendees.

* **Volunteer Abstracts**  
  Submissions are open for abstracts that showcase practical and compelling computational exercises.

* **Certification**  
  Earn a certificate by completing the challenges (feedback will be provided).
